## 海外の販売店を、開拓します。

日本のメーカー・ブランドの方へ。

フランスをはじめとする海外の小売店に、現地語で営業メールを送り、
返信を取ってくる仕事です。リストづくりから配信まで、まるごとお任せいただけます。

**やること**

1. 現地の小売店リストをつくる — 店名・住所・Google評価・メールアドレスまで
2. 現地語で営業メールを送る — 文面は2パターンで比較し、良いほうに寄せます
3. 結果を数えて毎月お渡しする — 何通届いて何件返ったか。指標の定義は変えません

**料金**（初期費用なし・税込）

- おためし … 5万円（単発／1都市・100件）
- 標準 … 月5万円（月300通の配信と月次報告）
- 商談まで … 月12万円（＋現地語の返信対応と商談設定／返信 月20件まで）

**やらないこと**

価格交渉・通関・輸送手配・売上の保証は含みません。
商談に同席はできますが、交渉の当事者にはなりません。商談から先はお引き継ぎします。
