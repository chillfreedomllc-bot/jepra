# 越境BtoB 販路開拓支援 ご提案

> **これはテンプレートです。** `〈 〉` で囲んだ箇所を案件ごとに書き換えてください。
> 数値は業界の一般的な水準にもとづく **想定レンジ** です。自社の実績が出たら
> `jepra stats` の出力に差し替えてください（実績がないうちに実績として出さないこと）。

## 1. ご提案の背景

海外に売れる商品を持ちながら販路開拓が進まない理由は、商品力ではなく **初期接触の
コスト** にあります。

- 現地の小売店リストが手に入らない（展示会名簿は古く、商社経由は選べない）
- 店舗名は分かってもメールアドレスが分からない（多くの店は問い合わせフォームのみ）
- 現地語で書けない、書いても反応がない
- 何通出して何件返ってきたのか分からないので、改善のしようがない

弊社〈自社名〉は、この **リスト構築から初回接触までの工程** を代行し、
すべて数値で報告します。

## 2. サービス内容

### プラン A — リード獲得（月額 8万円 / 初期 15万円）

現地小売リストの構築と、現地語でのアプローチ配信までを担当します。

| 内容 | 詳細 |
|---|---|
| ターゲット設計 | 対象国・都市・業種の選定、優先度の基準づくり |
| リスト構築 | 店舗情報の収集、重複排除、Google評価による優先度付け |
| 連絡先の特定 | 各店サイトを巡回してメールアドレスを特定。フォームのみの店は別リストへ |
| 文面作成 | 現地語で2パターン作成し、半数ずつ配信して反応を比較 |
| 配信 | 月300〜500通（初月は200通から開始） |
| 追客 | 7日間反応のない先へ1回のみフォロー |
| 月次レポート | 到達率・返信率・都市別の内訳・文面別の比較 |

**ご報告するKPI: 到達数と返信数**

### プラン B — 商談創出（月額 20万円 / 初期 20万円）

プランAに加えて、返信への対応と商談設定までを担当します。

| 追加内容 | 詳細 |
|---|---|
| 返信対応 | 現地語での一次返信、質問への回答、資料送付 |
| 見込み判定 | 前向き・条件付き・見送りに仕分け、理由を記録 |
| 商談設定 | 日程調整、オンライン会議の設定、通訳の手配（別途実費） |
| 引き渡し | 商談前に相手先の情報・関心事・経緯をまとめてお渡し |

**ご報告するKPI: 商談数**

成果報酬型（月額10万円 + 商談1件あたり2.5万円）へのご変更も可能です。

### トライアル（10万円 / 1ヶ月）

1都市・100件限定で、プランAの全工程を実施します。継続される場合は初期費用に充当します。

## 4. ご報告する数値

毎月、以下をお出しします。

```
ファネル
  収集した店舗              412
  メール取得済み             247  (60.0%)
  送信                   247
  　うちバウンス               13
  到達                   234  (94.7%)
  返信                    17  (7.3%)
  前向きな返信                9  (52.9%)
  商談化                    3  (1.3%)

文面 A/B（返信率）
  枝 A: 返信率 5.9%  枝 B: 返信率 8.5%
  差分: B が A より 2.6pt 高い / p値 0.095 → 傾向あり。次月はBに寄せます
```

**※ 上記は書式の例であり、実績値ではありません。**

指標の定義は以下で固定します。定義を毎月変えて数字をよく見せることはしません。

- **到達率** = (送信 − バウンス) ÷ 送信
- **返信率** = 返信 ÷ 到達（送信ではなく到達を分母にします。届いていない宛先を
  分母に入れると、文面の良し悪しが測れなくなるためです）
- **商談化率** = 商談 ÷ 到達

母数が少ない月は「参考値」と明記します。差が出ていないものを出たことにはしません。

### 想定レンジ

| 指標 | 想定レンジ | 補足 |
|---|---|---|
| メールアドレス取得率 | 40〜65% | 国と業種による。個人店が多い地域ほど低い |
| 到達率 | 90〜95% | 90%を下回る場合はリストの品質を見直します |
| 返信率 | 3〜10% | 商品と対象業種の相性に大きく左右されます |
| 商談化率 | 1〜3% | |

初月は文面の当たりが分からないため、レンジ下限を想定してください。
2〜3ヶ月目に比較結果が溜まり、数値が動きます。

## 5. 対応範囲外

後の食い違いを避けるため、明記します。以下は **本サービスに含みません**。

- 価格交渉・契約条件の取りまとめ
- 見積書・請求書の発行、代金回収、与信管理
- 輸送手配、通関、関税・輸入規制への対応
- 納品後のクレーム対応、返品処理
- 売上・受注の保証

商談の場に同席し議事録をまとめることは可能ですが、**交渉の当事者にはなりません**。
商談以降は貴社にお引き継ぎします。

## 6. 前提条件

- **商品資料**（写真・卸価格・最低発注額・納期・発送条件）を事前にご用意ください。
  これが揃っていないと返信が来ても商談に進みません。**最も多い停滞要因です。**
- 配信は貴社ドメインではなく弊社が用意する専用ドメインから行います
  （貴社ドメインの評価を守るため）。
- EU向けの配信には配信停止の導線を必ず入れます。停止のご要望があった先へは
  以降一切連絡しません。
- 対象国・業種の追加は 1件につき月額 +5万円で承ります。
- Google Places API の利用料は実費でご請求します（月あたり数千円程度）。
