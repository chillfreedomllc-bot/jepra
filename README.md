# jepra

ゲーム実況の生素材から、盛り上がっている場所を見つけて切り出すツール
（**kirinuki**）を置いているリポジトリです。

本体は `claude/claude-api-monetization-4bhzjp` ブランチの `kirinuki/` にあります。

```bash
cd kirinuki
pip install -e .
kirinuki scan 実況.mp4
```

Windows なら `kirinuki/` の中の `.bat` に動画をドラッグするだけでも動きます。
